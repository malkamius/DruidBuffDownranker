## New Features
- **PvP Protection**: Added a new safety feature that automatically skips PvP-flagged players if you aren't flagged yourself, preventing accidental flagging (disabled in dungeons and raids).
- **Targeting Priority**: The Smart Buff button now uses a smarter priority order: Self > Target > Mouseover > Group members. This ensures you are always buffed first before the button checks others.
- **Improved Mouseover Support**: The Smart Buff button now respects each spell's individual "Enable Mouseover" setting.
- **Quick Settings**: Added a "Don't Flag (PvP)" toggle to the Smart Buff button's right-click menu for quick access.

## Changes
- Increased the size of the Smart Buff button's right-click menu to accommodate the new PvP protection toggle.
